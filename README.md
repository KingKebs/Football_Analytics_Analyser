# Football Analytics Analyser

Python analytics for match prediction, corners, niche markets, and backtesting.

- **Run it:** `source venv/bin/activate` then `python cli.py --task help`
- **Docs index:** [ReadMeDocs/INDEX.md](ReadMeDocs/INDEX.md)
- **CLI cheat-sheet:** [ReadMeDocs/QUICK_REFERENCE.md](ReadMeDocs/QUICK_REFERENCE.md)
- **Agent notes:** [AGENTS.md](AGENTS.md)

Default branch is `dev`. Copy `config.example.yaml` to `config.yaml` before running.
